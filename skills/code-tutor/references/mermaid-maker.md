# Mermaid Maker — 인라인 다이어그램

mermaid는 **작고 국소적인 다이어그램**에 쓴다: 터미널 내 빠른 확인, 화이트보드·노트에 임베드하는 흐름/구조 도식.

> 전체 지식 그래프의 "한 눈에 + 확대/축소" 뷰는 mermaid가 아니라 **인터랙티브 HTML**로 만든다. [graph-html-maker.md](graph-html-maker.md)를 쓴다. (mermaid는 정적이라 대규모 그래프 탐색에 부적합.)

## 언제 mermaid

- 터미널에서 "지식 그래프 보여줘" → 대상 주변 **작은 서브그래프**를 mermaid로 즉시 렌더 (modes.md의 시각 확인).
- 화이트보드/노트의 **흐름·구조 도식**: 레이어(Controller→Service→Repository), 호출 체인, 상태 전이 등.

## 규칙

- 노드 라벨에 learning-state 이모지(있으면). 특수문자·괄호·공백 라벨은 `["..."]`로 감싼다.
- 엣지는 무방향 `---` (개념 그래프) 또는 방향 `-->` (흐름 도식).
- 10~15노드를 넘기면 mermaid 대신 HTML 그래프로 안내한다.
