# SVG Maker — 학습용 시각 자료 생성

텍스트나 mermaid보다 **그림이 이해를 크게 돕는 경우** SVG 시각 자료를 만든다. 생성은 `tutor-svg-maker` 서브에이전트(sonnet)에 위임하고, 결과 SVG를 화이트보드/노트에 임베드한다.

**활성 조건**: config.md의 첨부 폴더 경로가 있을 때(임베드하려면 저장 위치 필요). 경로가 없으면 인라인 SVG로 대체하거나 mermaid로 낮춘다.

## mermaid vs SVG — 무엇을 쓰나

| 상황 | 도구 |
|---|---|
| 구조·흐름·의존·상태 전이(레이어, 호출 체인, 그래프) | **mermaid** (가볍고 유지보수 쉬움) |
| 기하·공간·좌표·연속량, 커스텀 도식 | **SVG** |
| 예: Spring MVC 요청 흐름 | mermaid로 충분 |
| 예: 경사하강법의 가파른 기울기에서 진동·발산 | **SVG** (곡면·벡터·스텝을 그려야 직관적) |
| 예: B+Tree 노드 분할, 벡터장, 파형 | **SVG** |

원칙: **먼저 mermaid로 되는지 보고, 안 되는 시각(곡선·좌표·기하)일 때만 SVG.** 남발하지 않는다 — 그림이 텍스트를 실제로 능가할 때만.

## 절차

1. SVG가 적절하다고 판단되면 `tutor-svg-maker` 서브에이전트를 호출한다. 전달:
   - 무엇을 시각화할지(개념 + 강조점: 예 "경사하강법에서 큰 학습률이 가파른 기울기에서 발산하는 모습, 등고선 + 스텝 벡터").
   - 저장 경로: config.md의 첨부 폴더 + 파일명(`<소주제>-<설명>.svg`, 공백은 `-`).
   - 목표 크기(기본 720×480), 라이트/다크 모두에서 읽히게 `currentColor`/중립 팔레트 권장.
2. 에이전트가 SVG 파일을 저장하고 경로를 반환한다.
3. 화이트보드/노트에 `![[파일.svg]]`로 임베드한다.
4. (선택) 렌더가 의심스러우면 브라우저로 파일을 열어 스크린샷으로 육안 확인.

## 스타일 가이드 (에이전트에 전달할 기준)

- 학습용이므로 **레이블·축·범례**를 분명히. 장식 최소, 개념 전달 최대.
- 색은 의미에만(강조/대비). 배경 투명 또는 중립.
- 텍스트는 SVG `<text>`로(폰트 임베드 없이), 한글 포함 가능.
- 하나의 그림은 하나의 요점. 복잡하면 여러 장으로 나눈다.
